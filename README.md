Ссылка на игру https://buskoyyygmailcom.itch.io/heros-time

 Описание проекта: 3D шутер. Для победы нужно очистить землю от всехмонстров. Реализовано 3 уровня сложности, есть два типа оружья, 4 типа монстров.

Архитектура и подходы: 

 Компонентная архитектура

 Централизованный InputReader с событиями и настраиваемыми списками клавиш, движение осуществляется через CharacterController с собственной гравитацией и проверкой земли по LayerMask.

Система стрельбы реализована через Raycast, с эффектом попадания по точке и нормали. При получении урона игроком запускается Post Processing (Vignette).

В игре имеются:
 Bootstrap-сцена с инициализацией локализации и загрузкой главного меню.

Статический TimeManager для глобальной паузы (timeScale).

SceneSystem с типобезопасной загрузкой сцен по enum SceneName и перезапуском уровня.

 Система сложности врагов построена на ScriptableObject (DificultySettings) с пресетами здоровья и скорости врагов

Также реализованы  и применялись:

Анимация игрока и врагов с Mixamo 
ParticleSystem, PostProcessing, DoTween 
Интегрирована Yandex SDK с рекламой, локализацией и сохранениями 
AI врагов с помощью NavMesh
